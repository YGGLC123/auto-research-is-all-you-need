# Pair every reader-facing narrative with an internal binding ledger and a TODO file

(1) three files: reader (wording authority) / internal (state-word authority) / TODO (red blocks finalization); (2) shared grep-stable IDs N/C/D/R/F/S/G/Q/T; (3) Evidence Gate: no artifact -> not in D table -> not in prose; (4) slot discipline: readings fill the S table before the reader text; (5) three-flag self-audit (citation padding / hotspot / authority mask); (6) fresh-context restatement loop until zero drift, incl. one reviewer that recomputes.
